# 🗂️ Slim File Manager

Лёгкий кроссплатформенный файловый менеджер на **PySide6** с эмодзи-иконками вместо привычных пиктограмм, вкладками, drag&drop и встроенными мини-приложениями для просмотра/редактирования файлов.

## ✨ Возможности

- **📑 Вкладки** — несколько директорий одновременно, с независимой историей навигации
- **🧭 Breadcrumbs** — быстрая навигация по пути кликом на любой сегмент
- **📌 Сайдбар с закрепами** — стандартные папки (Home, Desktop, Downloads, Documents, Pictures) + свои через drag&drop
- **🖱️ Drag & Drop** — перетаскивание файлов между окнами и папками с выбором «переместить/копировать»
- **🔍 Поиск и сортировка** — фильтр по имени на лету, сортировка по имени / размеру / дате
- **🖼️ Сетка и список** — переключение вида, миниатюры изображений подгружаются асинхронно
- **👀 Панель предпросмотра** — иконка, метаданные, сниппет текстового файла
- **🖌️ Встроенные вьюеры**:
  - Просмотр изображений с зумом колёсиком мыши
  - Текстовый редактор (сохранение по Ctrl+S)
  - Просмотр содержимого ZIP-архивов
- **📦 Архивы** — сжатие в ZIP и распаковка прямо из контекстного меню
- **🐍 Запуск Python-скриптов** одним кликом
- **↩️ Undo** — отмена переименования, перемещения, копирования, создания файлов/папок
- **🗑️ Безопасное удаление** — через системную корзину (`send2trash`), либо безвозвратно, если пакет не установлен
- **⚙️ Персистентные настройки** — последняя открытая папка и закреплённые директории сохраняются между запусками (`QSettings`)
- **📋 Работа с буфером обмена** — копирование/вставка файлов и изображений (в т.ч. скриншотов из буфера)

## 🖥️ Установка

```bash
git clone https://github.com/yourusername/slim-file-manager.git
cd slim-file-manager
pip install -r requirements.txt
```

**requirements.txt**
```
PySide6
send2trash
```

> `send2trash` не обязателен — без него удаление будет работать напрямую (без возможности восстановить файлы).

## 🚀 Запуск

```bash
python file_manager.py
```

Также можно сразу открыть определённую директорию или файл:

```bash
python file_manager.py /path/to/folder
```

## ⌨️ Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Enter` | Открыть выбранный объект |
| `Space` | Показать панель предпросмотра |
| `Backspace` | Назад по истории |
| `Delete` | Удалить выбранное |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Копировать / Вырезать / Вставить |
| `F2` | Переименовать |
| `Ctrl+N` | Новая папка |
| `Ctrl+Shift+N` | Новый файл |
| `Ctrl+H` | Показать/скрыть скрытые файлы |
| `Ctrl+A` | Выделить всё |
| `Ctrl+L` | Фокус на поиск |
| `Ctrl+T` / `Ctrl+W` | Новая / закрыть вкладку |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Следующая / предыдущая вкладка |
| `Ctrl+P` | Показать/скрыть предпросмотр |
| `Ctrl+Z` | Отменить последнее действие |
| `Alt+←` / `Alt+→` | Навигация вперёд/назад |
| `F5` | Обновить список файлов |

## 🧩 Поддерживаемые типы файлов

Иконки автоматически подбираются по расширению: изображения, архивы, аудио, видео, документы Office, код, шрифты и т.д. Двойной клик открывает файл во встроенном вьюере (изображения, текст, ZIP) или запускает системный обработчик.

## 🛠️ Технологии

- [PySide6](https://doc.qt.io/qtforpython/) — GUI-фреймворк на базе Qt6
- [send2trash](https://github.com/arsenetar/send2trash) — кроссплатформенное удаление в корзину
- Фоновые операции (копирование/перемещение/загрузка миниатюр) вынесены в `QThread`, чтобы не блокировать интерфейс
