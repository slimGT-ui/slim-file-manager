## ОБЗОР

**slim file manager** — это надежный инструмент, спроектированный с упором на производительность и чистую архитектуру. Обеспечивает стабильную работу и высокую скорость отклика как на десктопных системах, так и в мобильных средах. Код написан так, чтобы его было легко читать, поддерживать и масштабировать.

## ОСОБЕННОСТИ

- **Производительность:** Оптимизированные алгоритмы с минимальным потреблением ресурсов.
- **Архитектура:** Модульный код без избыточности и костылей, готовый к расширению.
- **Кроссплатформенность:** Нативная поддержка Arch Linux, Kali и мобильных dev-сред.
- **Интеграция:** Гибкая настройка взаимодействия со сторонними API и базами данных.
- **UI/UX:** Строгий, адаптивный и интуитивно понятный интерфейс.

## СТЕК ТЕХНОЛОГИЙ

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (aiogram, Pygame)
- **Окружение:** Node.js, локальные серверы (code-server)
